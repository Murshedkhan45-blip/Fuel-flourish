FUEL & FLOURISH — PHONE APP STARTER

This folder contains a Progressive Web App (PWA). It is not yet online. To share it as a link, publish the files to a static HTTPS host, such as GitHub Pages.

EASIEST PUBLISHING ROUTE: GITHUB PAGES
1. On a computer, sign in or create an account at https://github.com
2. Create a new public repository, for example fuel-flourish.
3. Upload all files in this folder to the repository root (not the ZIP itself).
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose the main branch and /(root), then Save.
7. Wait for GitHub Pages to publish. The page will show a public URL, usually https://YOUR-USERNAME.github.io/fuel-flourish/
8. Open that URL on your iPhone and test it.

INSTALL ON IPHONE
1. Open the published HTTPS link in Safari.
2. Tap the Share icon (square with arrow pointing up).
3. Scroll and tap Add to Home Screen.
4. Name it Fuel & Flourish and tap Add.

INSTALL ON ANDROID
1. Open the HTTPS link in Chrome.
2. Tap the three-dot menu and choose Install app or Add to Home screen.

SHARE
Send the published URL to friends. They can open it on their phones and add it to their home screens.

IMPORTANT
- This starter is a simple web app, not an App Store / Google Play listing.
- The service worker enables basic offline caching after the first successful visit, when served over HTTPS. If you update the app later, the cache version may need changing in sw.js.
- The app saves shopping and meal ticks in the browser on each person's own device; it does not sync between devices.
- Do not upload private information or secrets to a public repository.
